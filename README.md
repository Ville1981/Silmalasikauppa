# Silmalasikauppa 👓

Täysi full-stack verkkokauppasovellus silmälaseille. Projektissa yhdistyvät modernit frontend- ja backend-teknologiat sekä tietoturvallinen käyttäjäkirjautuminen, tuotehallinta ja ajanvaraus.

---

## 🔧 Teknologiat

- **Frontend:** React + Vite
- **Backend:** Node.js + Express
- **Tietokanta:** MongoDB
- **Autentikointi:** JWT
- **Tyylit:** CSS / custom design
- **Muut:** Nodemailer, Helmet, CSP, Netlify

---

## 🚀 Käyttöönotto paikallisesti

### 1. Backend

```bash
cd backend
npm install
npm run dev

2. Frontend

cd frontend
npm install
npm run dev

3. Ympäristömuuttujat

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret_key
EMAIL_USER=youremail@example.com
EMAIL_PASS=your_email_password_or_app_password
